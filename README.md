# 🤖 AI Resume Analyzer

An AI-powered ATS (Applicant Tracking System) Resume Analyzer designed to help job seekers evaluate their resumes against job requirements and identify relevant skills and keywords.

## 📌 About the Project

The **AI Resume Analyzer** aims to simplify resume evaluation by analyzing resume content and helping users understand how well it aligns with job requirements. The project combines application development with resume analysis functionality to make the job application preparation process more efficient.

## ✨ Features

- 📄 Resume analysis
- 🎯 ATS-oriented resume evaluation
- 🔍 Keyword and skill matching
- 📊 Analysis results and insights
- 💻 Application interface for interacting with the analyzer

*Note: The features above should be retained only if they are implemented in the current version of your project.*

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Java, Spring Boot
- **Additional Components:** Python
- **Build Tool:** Maven

## ⚙️ Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Maven or the included Maven Wrapper
- Python, if required by the analysis component
- Node.js and npm, if the React frontend is maintained as a separate application

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/samaira90/ai-resume-analyzer.git
cd ai-resume-analyzer
```

**2. Build the Java application**

On Windows:

```bash
mvnw.cmd clean package
```

On macOS/Linux:

```bash
./mvnw clean package
```

**3. Run the application**

Follow the application's configured entry point and required environment settings. If the Python component is used separately, install its dependencies from the project's dependency file, if provided.
